Khushi Ghosh | Portfolio

Personal portfolio of a final-year EEE student who builds full-stack, backend and local-AI projects. Plain HTML, CSS and JavaScript: no frameworks, no build step.

What's on the site
About, Skills, Projects, Achievements, Writing, Contact in a single-page layout
Project cards rendered from one data array in script.js, with filters for Hacktoberfest, Full-Stack, AI and Hardware
Light and dark mode (remembers your choice), scroll-reveal sections, active nav highlighting
Responsive from phone to desktop, respects reduced-motion settings
Featured: Hacktoberfest 2026

Five open-source AI builds, all running on local open-weight models: Study Buddy, Same Spot, Order Ledger, Let It Die and Undead Agent.

Project structure
portfolio-website/
├── index.html   # markup and sections
├── style.css    # theme tokens, layout, responsive rules
├── script.js    # project/post data, filters, theme toggle, scroll effects
└── README.md
Editing content
Add or change projects in the projects array in script.js (add a repo URL to make a card clickable)
Add DEV post links to the posts array via url
Run locally
bash
git clone https://github.com/Khushighosh/portfolio-website.git
cd portfolio-website

Open index.html in your browser. No installation required.
